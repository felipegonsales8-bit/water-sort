# Potion Master

Projeto derivado de [sidhant947/water-sort](https://github.com/sidhant947/water-sort).

Este fork inicia a adaptação da apresentação do jogo para uma experiência temática de alquimia, preservando a mecânica original de classificação de líquidos.

## Conceito
Um aprendiz de alquimista organiza essências mágicas em frascos. Cada fase concluída representa um passo na restauração de seu laboratório.

## Stack
- Flutter / Dart
- Riverpod
- Hive
- Flame

## Plano de monetização
A proposta é usar anúncios recompensados opcionais para dicas ou segundas chances, sem interromper movimentos nem bloquear a progressão principal. Os anúncios só serão ativados após integração e testes com IDs próprios do AdMob.
